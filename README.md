# Scientific Calculator in C++

A command-line scientific calculator built using C++.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Square root
- Sine
- Cosine
- Tangent
- Natural logarithm
- Calculation history
- Clear result and history
- Continuous calculations
- Input-based menu system

## Technologies Used

- C++
- C++ Standard Library
- `<iostream>`
- `<cmath>`
- `<string>`
- `<sstream>`
